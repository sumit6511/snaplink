# SnapLink — Client

React + TypeScript + Vite frontend for SnapLink. See the [root README](../README.md) for full
project documentation, environment variables, and setup instructions.

```bash
npm run dev        # start the dev server (http://localhost:5173)
npm run build      # type-check and build for production
npm run typecheck  # type-check only
npm run lint       # run ESLint
```
